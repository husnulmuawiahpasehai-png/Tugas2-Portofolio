Pengalaman Saya

Selama SMA, saya pernah mengikuti beberapa kegiatan seperti Paskibra, OSIS, Ambalan, dan kegiatan kesenian. Selain itu, saya juga pernah terlibat dalam beberapa kegiatan kepanitiaan. Dari berbagai pengalaman tersebut, saya belajar untuk bekerja sama, berkomunikasi dengan baik, bertanggung jawab terhadap tugas, serta lebih disiplin dalam menjalankan kegiatan. Saat memasuki perkuliahan, saya mulai mendapatkan pengalaman dalam membuat project. Pada semester 1, saya bersama beberapa teman membuat aplikasi penghitung nilai mahasiswa secara berkelompok. Dari pengalaman tersebut, saya belajar tentang pemrograman sekaligus bagaimana bekerja sama dan menyelesaikan sebuah project bersama. Selain project kelompok, saya juga mengerjakan website portofolio ini secara mandiri. Melalui website ini, saya mencoba menerapkan apa yang telah saya pelajari sekaligus belajar membuat dan mengembangkan sebuah website sendiri.
